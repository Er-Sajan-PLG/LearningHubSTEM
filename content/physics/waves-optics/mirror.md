name: Mirror
domain: physics
status: draft
definition: >-
  A surface that reflects light. Plane mirrors produce virtual images of the same size; curved
  (concave and convex) mirrors can produce real or virtual images of varying sizes.
symbol: null
unit: null
equation: 1/f = 1/v + 1/u (mirror formula)
common_misconceptions:
  - All mirrors produce the same type of image (image type depends on mirror shape and object position).
  - Curved mirrors always magnify (depends on object position).
learning_objectives:
  - Distinguish between plane, concave, and convex mirrors.
  - Draw ray diagrams for image formation in curved mirrors.
  - Use the mirror formula to calculate image position.
  - Explain uses of different types of mirrors.
real_world_applications:
  - Rear-view mirrors (convex).
  - Shaving/makeup mirrors (concave).
  - Telescope mirrors (concave).
  - Security mirrors (convex).
